# 功能与已知限制

| 流程 | 可用功能 |
| --- | --- |

| 索引 | 手动指定结构、真实时间频率、重复 ID-time 拒绝、平衡性和组内缺期数 |
| 处理 | 删除/显式填补缺失、新列转换/对数/差分/滞后/中心化/标准化/交互/缩尾、条件筛选、版本与规则日志 |

| 展示 | 有效样本、配置、系数/SE/t-z/p/CI、适用 R²和整体 F、系数图、DID 事件图 |

| 扩展 | 用户主动设定稳健性规格、保存历史结果、样本一致性提示、共同样本重估、分组回归、两组 OLS 斜率差检验 |

## 明确限制

- 只支持共同政策时点 DID。检测出的分期实施会阻止；不能自动发现研究者在输入编码中隐藏的分期政策。
- 面板单位根、分期 DID、Difference-in-Hansen、wild-cluster bootstrap、多向聚类、FE HC3/HAC、FE/DID/GMM 组间系数差异检验尚未实现。
- 分类变量可用作组/索引/聚类；解释变量需先转数值或自行上传明确虚拟变量。公式没有 `C()`、任意函数/任意 Python，也不提供变量选择算法。
- 工作台在前端展示数据描述统计的前 15 个数值列；API 支持显式选取最多 40 个变量。模型有效样本统计依实际模型变量。超宽矩阵需水平滚动。
- 图形导出为 SVG，报告为 HTML；未提供 PNG/Word 原生导出。两者均满足需求中的二选一格式。
- 缩尾按当前版本全样本分位数，无自动分组缩尾；删除缺失、填补和变换均须用户主动发起。变换产生新列，不覆盖旧列。
- 事件图的区间逐点覆盖，不提供多重检验调整。组回归亦有多重检验和样本构成风险。
- 样本相同判断对数据值版本使用 SHA-256；变换版本不同会保守提示不一致。共同样本重估后仍需查看各模型实际 N；某些变换可能再次导致缺失。
- 一步 GMM 的系数/SE 是一步结果，AR/Hansen 来自库内部两步结果，界面和报告已说明。GMM 不提供 R²；工具变量数过大可被资源阈值拒绝。
- 没有用户账户、永久项目存储、团队共享或研究数据云同步。浏览器关闭不立即删除会话，闲置两小时/主动清理/服务停止清除。运行时 bearer token 在浏览器 sessionStorage，不写原始数据到浏览器存储。
- 当前部署为单进程 FastAPI 内存会话模型；本地默认最多两项统计任务，在线模板默认一项，单项 180 秒。需要多主机扩展时须改造外部任务队列和存储。已提供 Render 配置、在线数据告知及部署验收脚本，实际发布仍需要云账号和费用确认，见 DEPLOYMENT.md。
- 本次验证环境是 Windows + Python 3.12.14。提供 Docker Compose 与 Linux/macOS 启动脚本，但没有本机 Docker 实测；没有运行本地 Stata/R 软件。
- 报告定位为研究辅助初稿，需要研究者补充变量单位、识别设计和领域解释；不自动完成论文。
