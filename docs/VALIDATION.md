## 数值对照

| 检查 | 参考计算与容差 |
| --- | --- |
| OLS 系数 | 独立矩阵最小二乘，绝对容差 1e-10 |
| 常规 / HC1 / HC3 / CR1 | 独立构造协方差矩阵；SE 相对容差 1e-9；t 分布 p 值绝对容差 1e-10 |
| HAC | 独立 Bartlett 加权长程协方差与有限样本乘数，相对容差 1e-9 |
| 个体 / 时间 / 双向 FE | 不平衡面板，对照显式个体/时间虚拟变量 OLS，斜率和常规 SE 相对容差 1e-9；残差自由度一致 |
| 两期 DID | 对照处理/对照组前后四个均值的差分，绝对容差 1e-10 |
| DID 事件研究 | 基准相对期 -1、事件系数、政策前联合检验实际计算 |
| ADF | 零增广滞后的辅助回归 t 值，绝对容差 1e-10 |
| KPSS | 独立残差累积和与 Bartlett 长期方差，相对容差 1e-10 |
| Koenker–BP | 独立残差平方辅助回归 nR²，绝对容差 1e-9 |
| 系统 GMM | 公开 Arellano–Bond 数据；pydynpd 详细结果绝对容差 5e-7；独立 R panelvar 公开表的四位小数系数绝对容差 5e-5 |

GMM 基准为 `n` 的两阶动态模型，`w` 为预定变量、`k` 为外生变量；未折叠工具、无时间虚拟变量、两步系统 GMM。有效观测 **611**、个体 **140**、工具变量 **51**。

共同样本验收先建立两个有效样本不同的规格，再通过 API 得到交集配置并实际重估，两次估计的行号集合和 N 均等于交集。
